## Application Checklist
For every job application:
- [ ] Tailor resume bullet points to match job description keywords
- [ ] Check if company uses Airflow/dbt/Snowflake (match your stack)
- [ ] Customize cover letter with specific company data challenges
- [ ] Connect with someone at the company on LinkedIn first
- [ ] Follow up after 1 week if no response
- [ ] Prepare project walkthrough for phone screen
